# map_image ways walk native nodes; width is paint

Status: accepted

Ways assemble on shared native net nodes with same style only; coordinate snap and exact width no longer gate continuity, and a joined way carries a length-weighted width. This supersedes the same-width key in [0024](./0024-map-image-ways-not-grade-splits.md): lane drops no longer open beads, opposite carriageways still stay apart on distinct nodes, and elevation stays paint per 0024.
