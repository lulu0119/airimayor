# Player permissions are nine peer checkboxes

The player shows or hides tools with nine independent settings: construction, demolition, treasury and policy, development points, the clock, visual tools, saving, diagnostics, and panel control. Read tools stay listed. A hidden tool is left out of the catalog, and the prompt does not tell the model to call it. There is no read-only/mayor preset and no checkbox per tool. Panel control is not clipped by the other eight. Construction includes replacing a road's type between two points, using the same road walk as a parallel frontage.

## Considered Options

- **Two presets, read-only and mayor.** Rejected: the player mixes groups, and a preset hides which writes are on.
- **One checkbox per tool.** Rejected: the catalog is too large for a settings column, and the groups already match how the player thinks about the city.
