# A native edge is one grade; an embankment is ground

Status: accepted. Supersedes elevation-span paint in [0024](./0024-map-image-ways-not-grade-splits.md).

A Cities: Skylines edge is one piece of road. Its composition says elevated (bridge), tunnel, or ground. A raised embankment stays ground. Ways still join collinear edges of the same style, but not across that grade, so the bridge shell cannot cover the approach.
