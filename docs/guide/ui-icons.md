# UI icons

All UI glyphs come from [MingCute](https://icones.js.org/collection/mingcute) (Apache 2.0, see [`NOTICE`](../../NOTICE)). No hand-drawn SVG.

Mechanism: SVG under `Mod/UI/src/images/`, opaque `#fff` shapes, applied as `mask-image`. Colors are literals — this Gameface build drops `var()` in mod stylesheets.
